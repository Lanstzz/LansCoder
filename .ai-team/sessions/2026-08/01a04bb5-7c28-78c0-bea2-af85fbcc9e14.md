## 解决方案:选 "Entire account" 作用域

在 PyPI 的 [API token 页面](https://pypi.org/manage/account/token/) 创建 token 时:

- **Scope 选 `Entire account (all projects)`**,不要选单个项目。

- 单项目 scope 只列出已发布的包,`lanscoder-core` 首次发布后才会出现在列表里。
- 理论上可以"先手动上传一次 lanscoder-core,再回来建单项目 token",但这样既麻烦又和 CI 双 dist 同时上传的设计冲突,**不推荐**。

## 安全提醒

"Entire account" token 权限比单项目大,所以:
- 只放进 GitHub Actions Secrets,不要写进代码/文档/聊天记录。
- 如果怀疑泄露,随时可以在 PyPI 上撤销重建,再更新 Secrets。
