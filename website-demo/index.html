A coding agent you can read end to end

LansCoder is a locally-runnable Python coding agent with ~30k lines of clean, well-structured Python. Real enough to use daily, small enough to understand completely.

Features at a glance

⚙

Coding Agent

Understands your codebase, edits files, and runs shell commands. 40+ built-in tools cover file ops, search, git, and more.

◰

Multi-Model

OpenAI-compatible and Anthropic providers supported. Hot-switch models mid-session without restarting.

🔒

Permissions

Standard, aggressive, or bypass modes. Syntax-highlighted diffs previewed before every file mutation — even in high-permission mode.

⎘

Terminal UI

Built on Textual. Streams reasoning, tool calls, and results in real time. Autocomplete, session picker, diff review — all in the terminal.

💾

Sessions

Create, resume, fork, and share sessions. Persisted as JSONL. Full context recovery on restart.

🔗

MCP Integration

Connect external tool servers via Model Context Protocol. Extend the agent's capabilities with custom tools.

// How it's built

Architecture

Strict layering, clear dependency rules. Each module has one job.

lanscoder/ ├── app/ # Textual TUI — terminal interface, pickers, views ├── agent/ # Agent loop — orchestration, subagents, prompts ├── providers/ # Model adapters — OpenAI-compatible, Anthropic ├── tools/ # Tool registry — 40+ tools, execution sandbox ├── permissions/ # Policy engine — rules, grants, confirmations ├── context/ # Context management — 4-level compaction (L1–L4) ├── session/ # Session lifecycle — create, resume, fork, persist ├── mcp/ # MCP integration — external tool servers ├── memory/ # Cross-session persistent memory ├── skills/ # Local skill discovery and loading ├── config/ # TOML configuration — providers, models, settings └── utils/ # Shared utilities

Quick Start

1

Install

Install LansCoder with pipx (recommended) or pip:

$ pipx install lanscoder
2

Configure

Generate a config file, then edit it with your API key:

$ lanscoder config init $ vim ~/.config/lanscoder/config.toml
3

Example config

Set your default model and provider credentials:

# ~/.config/lanscoder/config.toml default_model = "deepseek/deepseek-v4-flash" [providers.deepseek] type = "openai-compatible" base_url = "https://api.deepseek.com" api_key = "sk-xxx" [models."deepseek/deepseek-v4-flash"] label = "DeepSeek V4 Flash" context_window = 1000000 [permissions] mode = "ask" [ui] theme = "default"
4

Launch

Run from your project directory:

$ lanscoder
